# سكرو — لعبة الورق العربية (أونلاين)

لعبة سكرو للأصدقاء، كل واحد يلعب من موبايله. السيرفر هو اللي بيشغّل قواعد اللعبة وبيبعت لكل لاعب كروته هو بس، فمحدش يقدر يشوف ورق غيره حتى لو فتح Inspect.

## اللعب
1. واحد يفتح اللعبة ويكتب اسمه ويضغط «اعمل غرفة جديدة» فيطلع كود من ٤ حروف.
2. «ابعت الدعوة لصحابك» بتبعت لينك فيه الكود، والباقي يفتحوه ويكتبوا أسماءهم.
3. المضيف يبدأ اللعبة (من ٢ لـ ٨ لاعبين). لو حد قفل المتصفح يقدر يرجع لنفس الغرفة من نفس الجهاز.

## التشغيل
تحتاج Node.js 20 أو أحدث.

```
npm install
npm run build
npm start
```
ثم افتح `http://localhost:3000`. لو صحابك على نفس الواي فاي، افتحوا `http://IP-جهازك:3000`.

## لعب عبر الإنترنت
- **سريع من جهازك:** شغّل `npm start` ثم `cloudflared tunnel --url http://localhost:3000` (أو ngrok) وابعت اللينك اللي يظهر.
- **دائم ومجاني تقريباً:** ارفع المشروع على GitHub وانشره على Render/Railway/Fly كـ Web Service.
  Build: `npm install && npm run build` — Start: `npm start`.
  (على الخطة المجانية السيرفر بينام لو مفيش حد، والغرف بتتمسح عند إعادة التشغيل.)

## للمطورين
- `npm run dev` يشغّل السيرفر (8787) والواجهة (3000) معاً.
- `npm run simulate` يلعب لعبة كاملة بلاعبين آليين ويتأكد إن مفيش كارت بيتسرّب (شغّل السيرفر أولاً على 3111: `npx tsx server/index.ts --port 3111`).
- `server/` السيرفر (HTTP + SSE بدون مكتبات خارجية)، `src/online/` الاتصال والغرف، `src/game/` محرك القواعد.
- الحد الأدنى للاعبين في الأونلاين ٢ (المحرك الأصلي كان ٤)؛ غيّره من `MIN_PLAYERS_ONLINE` في `server/room.ts`.
